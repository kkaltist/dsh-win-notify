# 提示音放这里

把 wav / mp3 丢进这个目录，**重启 DSH**，然后到
**设置 → 插件 → DSH 桌面通知** 的三个下拉框里选（选项里直接显示文件名，不用写配置）。

- 系统限制：自定义音频只认 **wav / mp3**，且 **时长 ≤ 10 秒**；超了或格式不对，整条通知会被系统丢掉。
- 内置三项不需要文件：`系统通知音` / `系统提醒音` / `静音`。
- 音效放在别处也行：设置里的「自定义音效目录」指向那个目录，下拉框会同时列出那里的文件。
- 想要不带文件名后缀的写法、或按场景分开指定，也可以直接编辑当前 profile 的配置：
  `~\.dsh\profiles\web\cordis.patch.yml` → `win-notify` → `sounds`。
